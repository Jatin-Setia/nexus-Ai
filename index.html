About NEXUS

A document assistant: upload PDFs and ask questions answered straight from their content.

What it is: An AI assistant that answers questions about the PDFs uploaded to it, using retrieval-augmented generation.

How it works: A question is converted into an embedding, matched against relevant document chunks using semantic search, and then passed to an LLM to generate a grounded response.

Documents connected: Whatever PDFs an admin has uploaded.

Built by: Jatin Setia · BCA · DBIT (GGSIPU)

📖 Document-first

Grounded in the PDFs you upload.

🔎 Semantic search

Vector retrieval over document chunks.

🔗 Cited sources

Each answer shows which document it drew from.
