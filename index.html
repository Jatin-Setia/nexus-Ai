About NEXUS

A focused academic assistant interface for the DBIT BCA syllabus project.

What it is: An AI assistant designed to answer questions about the DBIT BCA syllabus using retrieval-augmented generation.

How it works: A student's question is converted into an embedding, matched against relevant document chunks using semantic search, and then passed to an LLM to generate a grounded response.

Documents connected: BCA Scheme & Syllabus, University Ordinance 11 (exam rules), and the detailed 5th Semester syllabus — plus anything an admin has uploaded since.

Built by: Jatin Setia · BCA · DBIT (GGSIPU)

📖 Syllabus-first

Grounded in official academic documents.

🔎 Semantic search

Vector retrieval over document chunks.

🔗 Cited sources

Each answer shows which document it drew from.

🛡️ Admin uploads

Admins can add new syllabus PDFs live.

Enter to send · Shift + Enter for a new line · ⚡ for quick chat
